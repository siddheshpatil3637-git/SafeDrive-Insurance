About Project

SafeDrive Insurance Risk Assessment System

Project Overview

SafeDrive is a Flask web application that studies driving behavior from a CSV dataset. It predicts accident risk as Low, Medium, or High and estimates the insurance premium using TensorFlow models trained on tabular data.

Modules Used

  • Python and Flask for backend routes.
  • NumPy and Pandas for dataset generation, cleaning, and preprocessing.
  • TensorFlow for classification and regression models.
  • Pickle for saving and loading trained models.
  • Matplotlib and Seaborn for chart generation.
  • HTML, CSS, JavaScript, and Bootstrap for responsive pages.
